REGC TRUCKING SERVICES - OPERATIONS INSTALLATION
============================================

REQUIREMENTS
------------
- XAMPP with PHP 8+
- MySQL / MariaDB
- Apache
- Internet connection is recommended so Bootstrap and Bootstrap Icons CDN can load.

INSTALLATION
------------
1. Extract the folder "regc-lms" into:

   C:\xampp\htdocs\

2. Start Apache and MySQL in XAMPP.

3. Open phpMyAdmin:

   http://localhost/phpmyadmin

4. For a NEW installation, click "Import" and import:

   regc-lms/database/schema.sql

   Existing Phase 1 installations: keep your database. No reimport is needed.

5. Open Command Prompt in the regc-lms folder and run this command once:

   C:\xampp\php\php.exe database\seed.php

6. After the admin is created, login at:

   http://localhost/regc-lms/

GETTING STARTED
---------------
Sign in as administrator, then add Customers, Trucks, and Drivers.
Create a Shipment and assign an available truck and driver together.
Advance delivery status from the shipment details page.
Use Tracking to look up its generated tracking number.

See README.md for the workflow, restrictions, and test commands.
